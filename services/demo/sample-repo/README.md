# gca-sample

A tiny shop (Python and TypeScript) used by the [Gateway Code Attribution](https://github.com/nathan-james-s/gateway-code-attribution)
demo. `gca demo run` sends scripted coding sessions through the AI gateway, applies the returned edits here,
adds a few human edits, and opens a pull request so the **AI code attribution** check has something to show.

All code in this repository is synthetic and was written for the demo.

```bash
uv run --with pytest pytest
```
